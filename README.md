# Кораблик

Сверхлёгкая утилита для скриншотов на Windows 10/11 x64. Один `.exe` без установщика
и внешних зависимостей (статический CRT, только system DLL: user32/gdi32/shell32/advapi32/kernel32).
В простое: **~0.1 МБ Working Set / ~3 МБ Private Bytes, CPU 0%** — всё на событиях,
без таймеров, потоков и опросов.

## Права администратора и Steam

В манифесте стоит `requireAdministrator` — приложение всегда запускается с правами
администратора (нужно для захвата Steam и игр, работающих в привилегированных процессах;
как у ShareX). При запуске Windows будет спрашивать подтверждение UAC — это нормально.

Автозапуск: галочка «Запускать с Windows» в меню трея создаёт **задачу планировщика**
`schtasks /SC ONLOGON /RL HIGHEST /TN Korabl`, а не ключ реестра Run. Так она стартует
в молча, без UAC-окна при каждом входе в систему. Снять галочку — задача удаляется.

Если ставишь exe в папку «Автозагрузка» вручную (shell:startup) — тоже будет работать,
но при каждом логине появится запрос UAC. Рекомендуемый способ — галочка в трее.

## Возможности

| Действие | Клавиша по умолчанию | Результат |
|---|---|---|
| Скриншот монитора под курсором | **F18** | сразу в буфер обмена **и** в папку |
| Выделение области | **PrintScreen** или **F19** | оверлей → панель из 3 действий |

После выделения области:

- `1` или кнопка «1 · буфер+папка» (или `Enter`, или двойной клик) — сохранить и туда, и туда;
- `2` — только в буфер обмена;
- `3` — только в папку;
- `Esc` или правая кнопка мыши — отмена;
- выделение можно двигать (внутри рамки), тянуть за 8 маркеров, сдвигать стрелками (`Shift+стрелка` — по 10 px).

Файлы сохраняются как `1.png, 2.png, ...` — всегда наименьшее свободное число
(удалил `3.png` — следующий скриншот назовётся `3.png`). В буфер кладётся `CF_DIB`
(вставляется в Photoshop, Word, Telegram, браузеры) + дополнительно формат `PNG`.

## Сборка

Нужны: Visual Studio 2022 с нагрузкой «Разработка классических приложений на C++»
и Windows SDK 10 (10.0.18362+).

```bat
build.bat
```

Готово: `build\winshot.exe` (~218 КБ). Флаги: `/O2 /GL /LTCG /MT /Gy /OPT:REF /OPT:ICF /utf-8`,
подсистема `WINDOWS` с входом `mainCRTStartup`, манифест Per-Monitor DPI v2 вкомпилирован через `app.rc`.

## Настройка (settings.ini рядом с exe)

Файл создаётся автоматически при первом запуске. Кодировка — UTF-16LE или ANSI,
кириллица в путях работает.

```ini
[general]
screens_folder=D:\Документы\Screenshots   ; если диск недоступен — откат на %USERPROFILE%\Documents\Screenshots с уведомлением
autostart=0                               ; галочка «Запускать с Windows» в меню трея

[hotkeys]
full_monitor=F18                          ; скриншот монитора под курсором
region=PRINTSCREEN                        ; выделение области
region_secondary=F19                      ; второй хоткей области
```

Формат клавиш: `F1`–`F24`, `PRINTSCREEN` (он же `PRTSC`/`SNAPSHOT`), `SPACE`, `ENTER`,
буквы/цифры, модификаторы `CTRL+`, `SHIFT+`, `ALT+`, `WIN+` (например `CTRL+ALT+F20`).
Быстрые клавиши `F18`/`PrintScreen` можно поменять прямо из меню трея
(правая кнопка по иконке → «Изменить хоткей…», затем нажать новую клавишу) —
применяется сразу, без перезапуска; значение сохраняется в settings.ini.
Если клавиша занята другим приложением — придёт уведомление из трея с её названием.

### Клавиши F13–F24 и Macro Deck 3

Для бинда полностью доступны **F13–F24** — клавиши, которые почти никогда не заняты
другими программами. Это делает «Кораблик» отличной парой для **Macro Deck 3** и подобных
панелей (Stream Deck и т.п.): назначь F13–F24 на кнопки панели — и снимок всего монитора
или выделение области делаются одним нажатием кнопки на деке. Проверить работу этих
клавиш без физической клавиатуры можно, например, из AutoHotkey: `Send {F18}`.

## PrintScreen и системный Snipping Tool

Корабль перехватывает PrintScreen low-level хуком клавиатуры и **подавляет** системное
поведение клавиши, поэтому редактор «Фрагменты экрана» не открывается даже при включённой
настройке Windows. Если хотите и системную настройку выключить:

**Параметры → Специальные возможности → Клавиатура → «Использовать клавишу PrintScreen для
создания фрагмента экрана» → Откл.**

Также подавляется автоповтор (зажатая клавиша не откроет десять оверлеев).
OneDrive/Dropbox могут перехватывать PrintScreen для автосохранения — уберите их горячую
клавишу, если снимок делает Корабль.

## Замер памяти

Process Explorer (Sysinternals): найти `winshot.exe` → View → Select Columns →
вкладка **Process Performance**: столбцы **Private Bytes** и **Working Set**.
Ожидаемо в простое: WS < 1 МБ, Private ≈ 3 МБ.

Или PowerShell:

```powershell
$p = Get-Process winshot
'{0:N1} MB WS / {1:N1} MB Private' -f ($p.WorkingSet64/1MB), ($p.PrivateMemorySize64/1MB)
```

Если память выше ожиданий:

- убедитесь, что после снимка вызывается `trim_working_set()` (SetProcessWorkingSetSizeEx -1,-1);
- пиковая память во время самого снимка (буфер экрана + PNG) не считается — она освобождается сразу;
- проверьте, что оверлей закрыт: пока идёт выделение, он держит 2–3 полноэкранных буфера.

## Ограничения

- Захват идёт через GDI BitBlt: защищённый DRM-контент и некоторые полноэкранные игры
  (exclusive fullscreen) могут сниматься чёрными — это ограничение Windows/DX, не утилиты.
- Один экземпляр (именованный mutex); окно в панели задач отсутствует, выход — через меню трея.
- Автозапуск — задача планировщика `Korablik` с наивысшими правами (создаётся галочкой в меню трея).

## Тесты

`tools\pswin.ps1` — P/Invoke-хелпер (инъекция клавиш/мыши), `tools\test_*.ps1` —
сценарии проверки: F18, нумерация с «дырками», оверлей с протяжкой мышью, кнопки панели,
режимы 1/2/3, Esc/RMB-отмена. Запуск: `powershell -File tools\test_a_b.ps1` и т.д.
